# CMUmcl 0.3.0 Windows x64 本地交付

此版汇总当前已确认的客户端改动，使用正常账号登录、线上整合包清单及签名更新协议。没有跳过登录或内置模拟账号，也没有上传服务器、改变线上更新清单或推送仓库。

## 交付与使用

本地目录：`../releases/0.3.0/`。

- `CMUmcl-0.3.0-windows-x64.zip`：实际客户端。完整解压后双击 `CMUmcl.Start.exe`。
- `CMUmcl-0.3.0-source.zip`：对应工作区源码快照，包含主程序、更新器、原生引导器、测试及构建说明；包含本轮尚未提交的改动。
- `SHA256SUMS.txt`：两个交付 ZIP 的哈希。
- `verification/`：本地检查记录，不进入客户端 ZIP。

依赖已就绪时引导器直接打开客户端；缺少 .NET Desktop Runtime 10 x64 时显示已确认的安装提示，用户确认后从微软下载并安装。成功后自动进入客户端。引导器自身无需 .NET，安装过程中可能出现 Windows 管理员确认。此版包含最新版文案和“退出 / 取消”切换行为。

客户端数据默认位于 `%LOCALAPPDATA%\CMUmcl`。发行包不包含开发预览偏好、背景缓存、账号、游戏实例或 SDK。没有预设用户身份或游戏安装目录。

## 已包含的改动

- Java 自动/手动选择与游戏内存设置。
- 亮暗主题、背景设置、调整后的标题栏与整合包信息布局。
- 系统代理、直连、自定义 HTTP/SOCKS5 代理。
- 主题资源复用、图像解码优化和最小化时暂停自动换图。
- 原生依赖安装引导器，以及现有独立更新器。
