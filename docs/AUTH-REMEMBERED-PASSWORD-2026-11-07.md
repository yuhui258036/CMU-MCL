## 真实账号与进服验收

用户在本地候选版本退出后重新登录，亲自勾选“记住密码，登录失效时自动恢复”。此后没有再次输入密码。

1. **启动器重启恢复**：原令牌验证 HTTP 204，调用认证服务失效接口得到 204，再验证得到 403。关闭并重新打开候选启动器后，无登录窗口；自动恢复的新令牌与旧令牌不同，验证 204，凭据仍被保留。
2. **启动游戏时恢复**：再次使当前令牌失效并确认验证 403，仅点击一次原实例的启动按钮。客户端自动恢复登录、检查文件并启动 Java，无需再次点击启动或输入密码。
3. **游戏实际凭据**：游戏使用的令牌与新保存的会话一致、不同于失效令牌；角色 UUID 匹配，authlib 已加载，令牌验证 204。
4. **真实进服**：连接 `play.southmount.cn:25565`，已观察到服务器世界、玩家 HUD 和服务器计分板。游戏与本地候选启动器保持运行。
