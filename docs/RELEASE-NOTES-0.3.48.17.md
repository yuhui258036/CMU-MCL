# CMUmcl 0.3.48.17

新增可选的“记住密码，登录失效时自动恢复”。主动勾选后，客户端可以在会话失效或刷新结果无效时自动重新登录，继续原来的游戏启动，无需每次输入密码。密码使用 Windows 当前用户加密保护；退出登录时清除。未勾选时沿用手动重新登录。

自动恢复后仍校验新会话，并在启动游戏前再次确认。密码错误时停止自动尝试并提示手动登录；网络故障保留登录信息。后台验证与启动共享恢复流程，避免重复认证、重复窗口和旧结果覆盖新登录。

实例设置支持细分继承和即时保存，增加加载器与 Fabric API 管理、启动前文件完整性检查、崩溃报告导出、Modrinth 模组更新及启动后窗口行为设置。社区资源分来源渐进显示，增加图标缓存和预取；实例删除进入回收站。

修复整合包完整更新残留旧管理文件的问题，保留玩家自行添加的文件。原理图预览扩展继续保持可选安装和独立更新。
